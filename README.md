# 関連誌新刊号記事索引

JANUL（国立大学図書館協会）資料委員会による、海外関連誌の新刊号記事索引です。

- **表紙（index.md）**: 新着ストリーム ― 新しい号から順に全誌を一挙に掲載
- **journals/**: 誌別アーカイブ（誌ごとの収録範囲の確認用）
- **method.md**: 収録範囲・生成方法・既知の欠落

## 対象誌（8誌）

The Journal of Academic Librarianship / Learned Publishing / College & Research Libraries / Insights: the UKSG journal / Journal of Librarianship and Scholarly Communication / LIBER Quarterly / Journal of Scholarly Publishing / Evidence Based Library and Information Practice

## クレジットと生成について

本索引は JANUL 資料委員会が作成・公開します。記事情報の取得と日本語訳の下書きは AI アシスタント「Muse」が生成し、委員会が内容を確認のうえ公開しています。

## 更新について

新着は定期的に検出し、下書きを委員会が確認してから追記します。Git のコミット履歴が、そのまま更新と監修の記録になります。
